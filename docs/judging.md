## Two-hundred-submission test

The memorable sequence is not a list of integrations. A passing test suite is
followed by an autonomous digest-bound repair, then a deliberate refusal to
guess about payment behavior, then an accountable human decision, and finally
a checksummed `READY_TO_SHIP` artifact. The UI shows exactly which authority
each specialist held throughout.

Foreman's shortest differentiator is:

> Coding agents finish at code complete. Foreman starts there—and cannot say
> “ready” without evidence.
